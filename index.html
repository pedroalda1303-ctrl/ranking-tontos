Backup e restauração

Os jogos ficam numa tabela no Supabase, então todo mundo que abre o site alimenta a mesma base. Use o backup para guardar uma cópia fora dali e para importar o histórico da versão antiga.

“Somar” acrescenta os jogos do backup que ainda não estão na base. “Substituir tudo” apaga a base e coloca o backup no lugar, para todos os participantes.
